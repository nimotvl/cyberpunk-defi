# Cyberpunk Defi

> Cyberpunk-themed DeFi protocol with dark neon aesthetics

## Features

- Token swap
- Liquidity pools
- Yield farming
- DAO governance

## Tech Stack

- Frontend: HTML5, CSS3, JavaScript
- Blockchain: Solidity, Rust, Web3.js
- AI: MiMo V2 Flash, Claude Code

## Installation

```bash
git clone https://github.com/nimotvl/cyberpunk-defi.git
cd cyberpunk-defi
npm install
npm run dev
```
